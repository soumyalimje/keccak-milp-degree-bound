04

Algebraic Propagation Rules

The constraint logic the backend MILP model will encode, step-mapping onto Keccak's five internal transformations.

θ

Theta

Linear column XOR. Modeled bit-by-bit with standard COPY / XOR division-trail rules — not a simple max, so fan-out and cancellation are tracked exactly at trail level.

ρπ

Rho & Pi

Pure bit permutation — lanes rotate and translate. Just re-indexing in the model; degree is carried unchanged, no new constraints.

χ

Chi

The only nonlinear step. Modeled via the exact 5-bit division-trail table for y_i = x_i ⊕ x_i+1 ⊕ x_i+1·x_i+2 — not the naive max(deg A, deg B+deg C) additive rule, which overcounts shared variables.

ι

Iota

Round-constant XOR. Constants add no degrees of freedom to a monomial trail, so this step is not modeled — it only breaks symmetry between rounds.
